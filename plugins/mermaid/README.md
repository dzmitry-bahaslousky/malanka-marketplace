# mermaid

Render Mermaid diagrams in Claude Code with live reload. Preview flowcharts, sequence diagrams, ER diagrams, and more — the browser auto-refreshes as you iterate.

## Features

- Live-reload diagram preview in browser
- Supports flowcharts, sequence, class, ER, state, and Gantt diagrams
- Export to SVG, PNG, or PDF
- Multiple simultaneous diagrams via named preview IDs

## Prerequisites

- Node.js and npm installed

## Installation

```
/plugin install mermaid@malanka-marketplace
```

## Usage

Ask Claude to create any diagram:

- "Create a flowchart for the login process"
- "Draw a sequence diagram for the API auth flow"
- "Generate an ER diagram for my database schema"
- "Show the deployment pipeline as a diagram"
